# Security Policy

## Supported Versions

Security updates are provided for the latest stable version of AegleDllMSVC.

| Version | Supported |
|-|-|
| Latest release | ✅ |
| Older versions | ❌ |

---

## Reporting a Vulnerability

If you discover a security issue, vulnerability, or unexpected behavior that may affect the project, please report it privately.

Do not publicly disclose security vulnerabilities through GitHub Issues.

When reporting a vulnerability, include:

- Description of the issue
- Steps to reproduce
- Affected component
- Possible impact
- Logs or screenshots if applicable

## Response Time

Reports will be reviewed as soon as possible.

Depending on the severity of the issue, fixes may be released through:

- Patch updates
- Hotfix commits
- New releases

---

## Scope

Security reports may include:

- Memory safety issues
- Crashes
- Incorrect handling of user data
- Build system vulnerabilities
- Dependency issues
- Problems affecting project stability

Thank you for helping improve AegleDllMSVC.
